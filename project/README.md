# Simple To-Do App

Hey! This is a clean, minimal To-Do list I built to practice plain Vanilla JavaScript, HTML, and CSS.

## Features
- Type a task and hit Enter (or click Add)
- Check off tasks when you're done
- Delete tasks you don't need anymore

## How it works
- **HTML**: Standard structure.
- **CSS**: Just some Flexbox and 3 core colors to keep it looking neat and minimal.
- **JavaScript**: Hand-coded DOM manipulation. No frameworks, no external libraries. Check out `script.js`—the code is super straightforward!

## Running the app
Just open `index.html` in your browser. That's it!
